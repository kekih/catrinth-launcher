# 🚀 Catrinth Launcher (Minecraft) — Rust Edition

Официальный современный легковесный лаунчер Minecraft на языке **Rust** с красивой тёмной темой, встроенным каталогом модов через прокси-платформу Catrinth Hub и гибкими настройками игры.

![Catrinth Launcher Banner](https://raw.githubusercontent.com/pluxa1221/catrinth/main/app/static/icons/default-mod.svg)

---

## ✨ Основные возможности

* **🎨 Красивый тёмный интерфейс**:
  * Фирменная палитра Catrinth Hub (глубокий тёмный фон, изумрудные и фиолетовые акценты).
  * 100% плавный GUI на движке `egui / eframe` с мгновенным откликом (60+ FPS).
* **📦 Встроенный каталог модов и плагинов**:
  * Поиск по всей базе Modrinth и внутренним релизам Catrinth через прокси.
  * Фильтрация: Моды (Forge, Fabric, NeoForge), Плагины, Шейдеры, Текстуры.
  * **Установка в 1 клик**: прямое скачивание `.jar` файлов в папку `mods/` игры с отображением прогресса.
* **📁 Управление модами**:
  * Просмотр списка установленных модов в папке `.minecraft/mods`.
  * Быстрое удаление ненужных файлов и кнопка открытия папки в проводнике.
* **⚙ Гибкие настройки игры**:
  * **Смена папки игры**: легкий выбор любой кастомной директории игры через диалоговое окно или сброс на стандартную (`%APPDATA%\.minecraft`).
  * **Выделение оперативной памяти (RAM)**: удобный ползунок и быстрые кнопки пресетов (2 ГБ, 4 ГБ, 6 ГБ, 8 ГБ, 12 ГБ, 16 ГБ).
  * **Выбор Java Runtime**: указание пути к `javaw.exe` / `java` и кастомные JVM флаги оптимизации (`-XX:+UseG1GC`).
  * **Прокси-сервер Catrinth**: настройка адреса прокси с проверкой доступности.

## 📥 Как скачать лаунчер

Готовые скомпилированные версии для **Windows** и **Linux** автоматически собираются GitHub Actions при каждом обновлении:

1. Перейдите во вкладку [**Releases**](https://github.com/kekih/catrinth-launcher/releases).
2. Скачайте архив для вашей системы:
   * **Windows (x64)**: `catrinth-launcher-windows-x64.zip` (содержит готовый `catrinth-launcher.exe`).
   * **Linux (x64)**: `catrinth-launcher-linux-x64.tar.gz`.
3. Распакуйте в любую удобную папку и запустите! Установка дополнительных компонентов не требуется.

## 🛠 Сборка из исходников

Если у вас установлен Rust (`rustup` / `cargo`):

```bash
# Клонирование репозитория
git clone https://github.com/kekih/catrinth-launcher.git
cd catrinth-launcher

# Сборка оптимизированного релиза
cargo build --release
```

Готовый бинарный файл будет находиться в `target/release/catrinth-launcher.exe` (или `catrinth-launcher` на Linux).

## 🤖 Автоматическая сборка (CI/CD)

В репозитории настроен пайплайн **GitHub Actions** (`.github/workflows/build.yml`):
* Автоматически собирает исполняемые файлы под Windows x64 и Linux x64 на чистых виртуальных машинах.
* Публикует релизные архивы и артефакты, готовые к загрузке в один клик.
